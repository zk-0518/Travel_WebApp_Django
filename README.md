# Travel_WebApp_Django
This is a Django-based travel planning web application which contains features like gallery layout, recommendation system, itinerary generator through rule based logic, and login signup functions.

This website uses MongoDB as a database whose cluster is cloud based (Mongo Atlas).
A file is provided containing few datasets, to properly run this site you need to setup mongodb along with atlas on your system then change django settings to locate your database, then you can add your own data or use this file's datasets.

All the necessary files are uploaded.
